# GitHub Pages 部署指南

## 1. 创建仓库

推荐将仓库命名为 `你的用户名.github.io`，这样网站地址最简洁。

## 2. 上传文件

把网站文件推送到仓库的 `main` 分支。

## 3. 开启 Pages

进入 **Settings → Pages**，Source 选择 **GitHub Actions**。仓库自带的工作流会自动完成发布。

## 4. 等待部署

打开仓库顶部的 Actions 页面，绿色对勾出现后即可访问网站。
